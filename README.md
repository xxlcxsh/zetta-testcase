# Mini-RAG «Аккорд»

RAG-прототип для ответов на вопросы по правилам творческого центра. Поиск сочетает BM25 и dense-эмбеддинги `multilingual-e5-small` в FAISS, а результаты объединяются через RRF. Поскольку корпус документов представлен малым объёмом и в достаточно нативном виде (без неопределённостей и т.п.) реранкер не посчитал нужным внедрять, но стоит упомянуть, что при увеличении корпуса документов и усложнении их структуры хорошим решением будет внедрить реранкер и query-rewrite для лучшего результата. Предусмотрено два режима работы: возврат релеватного объекта и формирование ответа с помощью llm на основе релеватного контекста.

## Режимы работы

- chunk — возвращает найденные фрагменты документов без генерации.
- llm — передаёт найденные фрагменты в контекст Qwen/Qwen3-0.6B и возвращает краткий ответ.

В обоих режимах отдельно возвращаются ID документа и дословная цитата. Архивные документы фильтруются и не попадают в индекс.

## Запуск

Python 3.10–3.12. (выше не проверял)

```bash
python -m venv .venv
```

Windows:

```powershell (внутри venv, аналогично на linux)
pip install -r requirements.txt
uvicorn app:app --reload
```
Сервис доступен на <http://127.0.0.1:8000>. Swagger доступен на <http://127.0.0.1:8000/docs>.

При первом запуске будет скачана модель Qwen. Qwen загружается при первом запросе в режиме llm; на CPU генерация может занять некоторое время.

## Evals

```bash
python evaluate.py --mode chunk
python evaluate.py --mode llm
```

Результаты сохраняются в `results_chunk.csv` и `results_llm.csv`. Оба режима проходят 7/7 проверочных вопросов.
