# Mini-RAG «Аккорд»

RAG-прототип для ответов на вопросы по правилам творческого центра с веб-интерфейсом. Поиск сочетает BM25 и dense-эмбеддинги `multilingual-e5-small` в FAISS, а результаты объединяются через RRF. Поскольку корпус документов представлен малым объёмом и в достаточно нативном виде (без неопределённостей и т.п.) реранкер не посчитал нужным внедрять, но стоит упомянуть, что при увеличении корпуса документов и усложнении их структуры хорошим решением будет внедрить реранкер и query-rewrite для лучшего результата. Предусмотрено два режима работы: возврат релеватного объекта и формирование ответа с помощью llm на основе релеватного контекста.
Результаты в формате .csv сохраняются как при прогоне в eval, так и при прогоне в веб-интерфейсе. 

## Режимы работы

- chunk — возвращает найденные фрагменты документов без генерации (работает сразу, ничего не требует)
- llm — передаёт найденные фрагменты в контекст Qwen/Qwen3-0.6B и возвращает краткий ответ. (возможна задержка при первой генерации, т.к. необходимо скачать модель с huggingface), модели сохраняются в 'C:\Users\<имя_пользователя>\.cache\huggingface\hub\'

В обоих режимах отдельно возвращаются ID документа и дословная цитата. Архивные документы фильтруются и не попадают в индекс.

## Запуск

Python 3.10–3.12. (выше не проверял)

```bash
python -m venv .venv
```

Windows (внутри venv, аналогично на linux/MacOS):

```powershell
pip install -r requirements.txt
uvicorn app:app --reload
```
Сервис доступен на <http://127.0.0.1:8000>. Swagger доступен на <http://127.0.0.1:8000/docs>.

Qwen загружается при первом запросе в режиме llm (не удивляйтесь, если первый запрос будет долгим; на CPU генерация может занять некоторое время.

## Evals

```bash
python evaluate.py --mode chunk
python evaluate.py --mode llm
```

Результаты сохраняются в `results_chunk.csv` и `results_llm.csv`. Оба режима проходят 7/7 проверочных вопросов.
